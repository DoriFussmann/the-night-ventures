AI Assistant Prompts

Prompt Builder

Turn each persona into the prompts that person would type into an AI assistant, then review and approve them. Every prompt belongs to one persona, one buyer situation and one stage.

Input

Saved Personas

Pick the saved persona set to write prompts for. Its ICP supplies the buyer situations, alternatives and question variables.

Output

Saved Prompt Sets

Work in progress is kept in this browser. Save a set to keep it with the page and reopen it later.

Input · Once Per Brand

Tracked Brands

The company itself and its competitors. The own brand's name patterns are banned from prompts. Domains and exclude patterns are used later, when prompts are tested. Separate several values with commas.

Summary

Prompts

Generation settings

Duplicates are judged by Claude against every prompt for the brand, across all personas. There is no numeric similarity threshold in this page.

Personas

Prompts by Persona

One column per persona. Coverage shows prompts you have against the target for each situation and stage. Rejected prompts stay stored so they are not written again.

Persona Mix

Set the total, then how much of it each persona gets. Weights start from the prompt share in the personas and can be any numbers; only their proportion matters. Changing a weight never deletes a prompt.

Generate All

One run for every persona: checks the prompts already here, approves drafts that passed and rejects the rest, rejects the extras of any persona over its target, then writes each persona up to its target. It ends with no drafts. A prompt that passes the checks is saved as Approved. One that could be a duplicate or be misread is rewritten up to three times, then dropped. Saving and pushing stay with you.
