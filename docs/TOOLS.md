# The Night Ventures — Tools Guide
Last updated: August 3, 2026

## What this app is

The Night Ventures app is a shared workspace for managing website and growth work across multiple companies. You pick a company, then use tools for that company’s profile, accounts, tasks, and design materials. Some reference documents apply to every company the same way.

## General Tools (same across all companies)

### Site Build Prompt

- **What it does:** Holds shared reference documents used when building websites — including a site build prompt, a site build checklist, and a design system prompt. You can edit each document, save changes, copy the text, or download it. Edits here apply to every company.
- **Who would use it and why:** Team members who run or hand off site builds. It’s the single place for the standard prompts and checklists everyone should follow, so work stays consistent from one project to the next.

## Company Tools (scoped to one company at a time)

### Company Data

- **What it does:** Stores the company’s core profile: domain, product name, and short-to-long descriptions, plus any custom fields you add. You can save the profile and download it as a readable document. SEO structure lives here too: pillar keywords, each with supporting keywords under it, which feed the Topic Generator. You can also maintain a known competitors list (name + URL) used when planning article clusters.
- **Who would use it and why:** Anyone writing copy, briefs, or content for that company. It’s the home base for “who is this company and how do we describe them?” and for the keyword architecture content planning depends on.

### Social & Shops

- **What it does:** Tracks social accounts, digital stores, and other online presence for the company. For each entry you can record name, type, status, link, username, access details (hidden until you reveal them), and comments. You can also keep freeform notes for the company.
- **Who would use it and why:** People who manage logins, handoffs, or channel setup. It keeps account info and access details in one place instead of scattered messages or spreadsheets.

### Site Tasks

- **What it does:** A task list for the website build: each item has a name, comments, an owner, and a status (for example not started, in progress, or done). You can add, edit, and remove items.
- **Who would use it and why:** Project leads and builders tracking what still needs doing on the site. It’s a simple checklist so nothing gets lost mid-build.

### Biz Dev Tasks

- **What it does:** Same kind of list as Site Tasks, but for business development initiatives — item, comments, owner, and status. You can add, edit, and remove items.
- **Who would use it and why:** Anyone owning partnerships, outreach, or growth work for that company. It keeps biz-dev follow-ups visible next to the rest of the company’s tools.

## SEO Tools (scoped to one company at a time)

### Design Builder

- **What it does:** Helps you build a full design guide for the company — brand feel, colors, fonts, layout, imagery, voice, and related choices. You can fill fields by hand, drop in brand files (images, PDFs, or text) to pull ideas in, use AI to suggest missing pieces, save the guide, and download or copy it. You can also save the current setup as a reusable project theme and load or delete themes later.
- **Who would use it and why:** Designers, builders, and anyone briefing a website look and feel. It turns scattered brand notes into one exportable design guide, with AI help to fill gaps so you don’t start from a blank page.

### Specific Prompt

- **What it does:** Placeholder for turning templates into company-specific prompts. Not built yet (shows “Coming soon”).
- **Who would use it and why:** Will support prompt handoffs that start from a shared template and get tailored to one company.

### Topic Generator

- **What it does:** Tracks SEO content coverage from Company Data’s pillar and supporting keywords. For each supporting keyword you can plan an article cluster with AI (paste optional Semrush keyword data, review a proposal, steer and regenerate, then confirm). Confirmed clusters store planned articles plus the cluster rationale, let you cycle article status (planned → drafted → published), and download the cluster as markdown.
- **Who would use it and why:** Content and SEO leads mapping which topics are covered and planning non-overlapping article clusters under each supporting keyword.

### Article Generator

- **What it does:** Placeholder for writing full SEO articles from planned topics. Not built yet (shows “Coming soon”).
- **Who would use it and why:** Will turn confirmed cluster briefs into draft articles.
